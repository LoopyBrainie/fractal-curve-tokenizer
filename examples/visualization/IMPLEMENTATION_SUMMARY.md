## 一、数学形式化分析

### 1.1 核心数学组件审查

#### Hilbert 曲线实现 (curve_hilbert.py)

**数学定义：**
```
H: [0, n²) ↔ [0, n) × [0, n), n = 2^k
```

**关键性质验证：**
- ✅ **双射性**：`xy_to_d` 和 `d_to_xy` 互为逆函数
- ✅ **局部性保持**：‖p₁-p₂‖₂ ≤ C·|H⁻¹(p₁)-H⁻¹(p₂)|^(1/2)
- ✅ **算法复杂度**：O(log n) 时间，O(1) 空间
- ✅ **缓存策略**：LRU 缓存 4096 个结果，有效避免重复计算

**工程实现评价：**
- 使用标准的 Gray 码算法，正确性有保证
- Pseudo-Hilbert 扩展支持任意尺寸，采用混合策略（阈值 ρ* = 4/3）
- 代码使用 `torch._dynamo.disable` 确保与 `torch.compile` 兼容

#### 自适应四叉树分词 (split_adaptive.py)

**数学形式化：**
```
C_θ(R) = σ(MLP(ROI-Align(F, R)))
Split(R) ⟺ C_θ(R) > τ_d ∧ d < d_max ∧ size(R) ≥ min_size
```

**Gumbel-Softmax 松弛：**
```
z = GumbelSoftmax(log p_split, τ(t))
τ(t) = τ_max · (τ_min / τ_max)^(t/T)
```

**关键发现：**
- ✅ **端到端可微**：通过 Gumbel-Softmax + STE 实现
- ✅ **无饱和问题**：MLP 优于基于方差的复杂度函数
- ✅ **可学习阈值**：τ_d = τ_base,d + δ_d，自适应调整
- ⚠️ **温度退火**：需要 T_end ≥ 0.3 避免梯度消失（P11-11 修复）

**辅助损失函数：**

1. **Barrier Loss (阈值约束)**
   ```
   L_barrier = λ·Σ_d [max(0, τ_min - τ_d)² + max(0, τ_d - τ_max)²]
   ```
   - Dead Zone: τ ∈ [-3, 3] 时无梯度干扰
   - λ = 5.0，确保边界安全

2. **Elastic Budget Loss (弹性预算)**
   ```
   L_elastic = λ_over·φ(N - N_max) + λ_under·ψ(N_min - N)
   N_soft = Σ_d R_d·(1 - p_d)
   ```
   - 软 Token 计数：期望叶节点数
   - 梯度流：同时考虑直接和间接效应

3. **Soft Entropy Loss (软熵损失，P10-13 改进)**
   ```
   L_entropy = KL(p || u) + w·ReLU(p_max - θ)²
             = [log(D+1) - H] + w·ReLU(p_max - θ)²
   ```
   - 始终非负：L ∈ [0, log(D+1)]
   - 最小值在均匀分布：L = 0 当 p(d) = 1/(D+1)
   - 反崩塌机制：θ = 0.8, w = 1.0

4. **Soft 2:1 Balance Loss (软平衡损失)**
   ```
   L_balance = Σ_(i,j)∈Adj max(0, |d̃_i - d̃_j| - 1)²
   d̃_i = Σ_d d·P(depth_i = d)
   ```
   - 完全可微：通过软深度期望
   - 维护 Hilbert 曲线 2:1 约束

#### LCA 注意力偏置 (attn_hilbert_bias.py)

**数学定义：**
```
B[i,j] = τ_h · LCAEmbed(LCA(i,j))
LCA(i,j) = max{k : path_i[0:k] = path_j[0:k]}
```

**参数效率分析：**
- **Standard ViT**: B ∈ ℝ^(N×N)，需要 O(N²) 参数
- **Fractal ViT**: LCAEmbed ∈ ℝ^((d_max+1)×H)，需要 O(log N·H) 参数
- **参数减少**：约 99.8%（对于典型的 N）

**温度缩放（P6-2）：**
```
τ_h = softplus(γ_h)
```
- 初始化使 τ_h ≈ 1.5，提供 1.5σ 的空间先验
- 每个头独立学习最优空间偏好强度

**向量化 LCA 计算：**
```python
matches[i,j,k] = (path_i[k] == path_j[k])
cumulative_match[i,j,k] = ∏_{k'≤k} matches[i,j,k']
lca_depths[i,j] = Σ_k cumulative_match[i,j,k]
```
- 复杂度：O(B·N²·D)，但在 GPU 上完全并行
- 缓存策略：使用 WeakRef 避免 data_ptr 重用碰撞（P11-1）

### 1.2 数学正确性评估

✅ **正确性**
- Hilbert 曲线：标准算法，通过单元测试验证
- LCA 计算：向量化实现，数学等价于递归定义
- 四叉树结构：维护 2:1 平衡约束可微
- 注意力机制：标准多头注意力加有效几何偏置

✅ **数值稳定性**
- Softmax 截断：logits ∈ [-20, 20] 防止溢出
- Epsilon 项：ε = 10^-8 防止 log(0)
- Softplus 激活：确保正值 σ_scale > 0
- FP32 强制：关键计算避免 FP16 精度问题（P10-NaN-17）

⚠️ **收敛性质**
- 温度退火：对收敛至关重要，低温（T < 0.3）导致梯度消失
- 辅助损失平衡：需要调优，失衡导致崩塌或预算违规
- Dead Zone：Barrier 和 Elastic 损失有死区，健康训练时无梯度干扰

     - 熵比率：H/H_max ∈ [0, 1]

   - 块状结构：同一父节点的 Token 有高 LCA

5. **对比分析 (`plot_comparative_analysis`)**

## 四、与传统 ViT 的核心差异

| 维度 | Standard ViT | Fractal ViT |
|------|-------------|-------------|
| **分词方式** | 固定 16×16 网格 | 自适应四叉树（4×4 ~ 32×32）|
| **Token 数量** | 恒定 N = HW/P² | 可变 N ∈ [N_min, N_max] |
| **排序方式** | 光栅扫描（行优先）| Hilbert 曲线（保持局部性）|
| **位置编码** | 可学习 N² 偏置 | LCA: (d_max+1)×H ≈ log N |
| **归纳偏置** | 无 | 空间局部性 + 多尺度结构 |
| **参数效率** | O(N²) | O(log N·H)，减少 99.8% |

### 数学优势

1. **内容自适应**：根据局部复杂度分配 Token
   - C(R) = α·C_var(R) + (1-α)·C_grad(R)
   - 复杂区域获得更多 Token

2. **参数高效**：位置偏置参数大幅减少
   - Standard ViT: N² ≈ 256² = 65,536
   - Fractal ViT: (d_max+1)×H ≈ 5×8 = 40
   - 减少：99.94%

3. **局部性保持**：Hilbert 曲线维护 2D 空间连贯性
   - ‖p₁-p₂‖₂ ≤ C·|H⁻¹(p₁)-H⁻¹(p₂)|^(1/2)
   - 相邻 Token 在序列中也接近

4. **多尺度表示**：自然地在多个分辨率表示对象
   - 深度分布熵 H > 1.0 表示良好的多尺度多样性

### 适用场景

✅ **Fractal ViT 适合：**
- 复杂度变化的图像（自然场景、医学图像）
- 计算预算有限（自适应 Token 分配）
- 需要可解释性（显式空间结构）
- 多尺度特征学习

⚠️ **考虑 Standard ViT：**
- 均匀图像（文档、纹理）
- 需要最大吞吐量（固定计算）
- 更简单的实现
